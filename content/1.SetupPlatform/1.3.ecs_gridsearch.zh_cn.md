## 使用 ECS 批量运行 Python 任务

{{% notice note %}}
本实验建议在 us-east-1 区域进行。
{{% /notice  %}}

**这部分内容将展示如何通过 AWS SDK 批量在 ECS 中运行容器。这可以用于并行运行 python 代码。**

在量化研究中经常遇到需要对超参进行优化的问题，不同的超参可能会对策略的表现有决定性的影响。对超参优化简单粗暴的处理方式就是进行网格搜索（grid search），这尤其适用于一些超参组合不多的场景。在下面的示例中，我们将展示如何通过容器技术，在 AWS ECS 服务中大量进行并行的网格搜索。
