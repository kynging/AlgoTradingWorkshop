## 使用 ECS 批量运行 Python 任务

{{% notice note %}}
本实验建议在 us-east-1 区域进行。
{{% /notice  %}}

**这部分内容将展示如何通过 AWS SDK 批量在 ECS 中运行容器。这可以用于并行运行 python 代码。**

在量化研究中经常遇到需要对超参进行优化的问题，不同的超参可能会对策略的表现有决定性的影响。对超参优化简单粗暴的处理方式就是进行网格搜索（grid search），这尤其适用于一些超参组合不多的场景。在下面的示例中，我们将展示如何通过容器技术，在 AWS ECS 服务中大量进行并行的网格搜索。

### 搭建 ECS 示例程序

![](/images/1.3.ecs_gridsearch/architecture.png)

在这个环节，我们会先在 ECS 上搭建一个示例应用。如果您之前对 Docker 并不是很熟悉，这个环节可以帮助您快速掌握容器技术的一些基础知识。

- 下载此环节使用的 Notebook 代码到本地：[1.3.1.ecs_sample_app.ipynb](/files/1.3.1.ecs_sample_app.ipynb)
- 回到 JupyterLab 界面，点击左上角的**上传**按钮：
![](/images/1.3.ecs_gridsearch/upload_notebook.png)

- 选择刚刚下载的 **1.3.1.ecs_samle_app.ipynb** 文件并上传。上传成功后打开 Notebook：
![](/images/1.3.ecs_gridsearch/sample_app_notebook.png)

接下来逐个 cell 执行 Notebook 代码就可以了。您可能注意到代码中主要使用 Boto3（AWS Python SDK）进行了如下操作：

- 创建了名为 **ecs-demo-php-simple-app** 的 ECR 镜像仓库，这将用于存储 Docker 镜像： 
```
ecr.create_repository(repositoryName=repository_name)
```
- 创建完成之后，可以导航到 ECR 控制台：[https://us-east-1.console.aws.amazon.com/ecr/repositories?region=us-east-1](https://us-east-1.console.aws.amazon.com/ecr/repositories?region=us-east-1)
- 这里可以看到新创建的镜像仓库：
![](/images/1.3.ecs_gridsearch/sample_app_ecr.png)

- 接下来构建 Docker 镜像并将其推送到镜像仓库：
```
!docker build ecs-demo-php-simple-app -t ecs-demo-php-simple-app
!docker tag ecs-demo-php-simple-app {aws_account_id}.dkr.ecr.{aws_region}.amazonaws.com/{repository_name}
!aws ecr get-login-password | docker login --username AWS --password-stdin {aws_account_id}.dkr.ecr.{aws_region}.amazonaws.com
!docker push {aws_account_id}.dkr.ecr.{aws_region}.amazonaws.com/{repository_name}
```
- 成功之后可以点开之前的镜像仓库页面，看到推送的镜像：
![](/images/1.3.ecs_gridsearch/sample_app_image.png)

- 创建 **ECS 任务定义**。代码中定义了任务需要使用的容器镜像和一些基础配置：
```
ecs.register_task_definition(
    family="sample-app",
    volumes=[
        {
            "name": "my-vol",
            "host": {}
        }
    ],
    networkMode="awsvpc",
    executionRoleArn="arn:aws:iam::{}:role/ecsTaskExecutionRole".format(aws_account_id),
    containerDefinitions=[
        {
            "name": "simple-app",
            "image": "{}.dkr.ecr.{}.amazonaws.com/{}:latest".format(aws_account_id, aws_region, repository_name),
            "portMappings": [
                {
                    "containerPort": 80,
                    "hostPort": 80,
                    "protocol": "tcp"
                }
            ],
            "mountPoints": [
                {
                    "sourceVolume": "my-vol",
                    "containerPath": "/var/www/my-vol"
                }
            ],
            "entryPoint": [
                "/usr/sbin/apache2",
                "-D",
                "FOREGROUND"
            ],
            "essential": True
        },
        {
            "name": "busybox",
            "image": "busybox",
            "cpu": 10,
            "memory": 500,
            "volumesFrom": [
            {
              "sourceContainer": "simple-app"
            }
            ],
            "entryPoint": [
                "sh",
                "-c"
            ],
            "command": [
                "/bin/sh -c \"while true; do /bin/date > /var/www/my-vol/date; sleep 1; done\""
            ],
            "essential": False
        }
    ],
    requiresCompatibilities=["FARGATE"],
    memory="512",
    cpu="256"
)
```
- 完成之后，可以导航到 ECS 控制台的 Task Definitions 界面：[https://us-east-1.console.aws.amazon.com/ecs/home?region=us-east-1#/taskDefinitions](https://us-east-1.console.aws.amazon.com/ecs/home?region=us-east-1#/taskDefinitions)
- 可以看到刚刚创建的任务定义：
![](/images/1.3.ecs_gridsearch/sample_app_task_definition.png)

- 创建好的任务定义有一个 Amazon 资源名称（ARN），请复制 **'taskDefinitionArn'** 的值到下一个 cell 中：
![](/images/1.3.ecs_gridsearch/sample_app_task_definition_arn.png)

- 同时，请导航到 CloudFormation 控制台：[https://us-east-1.console.aws.amazon.com/cloudformation/home?region=us-east-1#/stacks?filteringStatus=active&filteringText=&viewNested=true&hideStacks=false
- 在 AlgoTradingWorkshop 堆栈的 **Output** 页面下，寻找三个公有子网的 id 和 **HTTPSecurityGroup** 的 id 复制到下一个 cell中：
![](/images/1.3.ecs_gridsearch/public_subnets.png)

- 完成上述步骤之后，继续执行Notebook中的代码，最后就可以在 Fargate 中创建容器来运行示例程序了
- 导航到 ECS 控制台的集群界面：[https://us-east-1.console.aws.amazon.com/ecs/home?region=us-east-1#/clusters](https://us-east-1.console.aws.amazon.com/ecs/home?region=us-east-1#/clusters)
- 点击 **AlgoTradingWorkshop** 集群：
![](/images/1.3.ecs_gridsearch/ecs_cluster.png)

- 再点击 **Task**：
![](/images/1.3.ecs_gridsearch/sample_app_task.png)

- 在task的详情界面中，找到 **Public IP**，此地址为示例应用的公网服务地址
![](/images/1.3.ecs_gridsearch/sample_app_ip.png)

- 在浏览器中输入此地址，就可以访问示例应用了

![](/images/1.3.ecs_gridsearch/sample_app.png)
