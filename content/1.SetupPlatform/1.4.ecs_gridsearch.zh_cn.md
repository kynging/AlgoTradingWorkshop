## 使用 ECS 批量运行任务

{{% notice note %}}
本实验需要在us-east-1区域进行。
{{% /notice  %}}

把上一个环节的超参优化任务放到 ECS 里通过 grid search 来实现，然后画个 heatmap 来看看之前超参优化的效果：
- 详细介绍 ECS 服务和 Fargate
- 在 ECS 控制台中定义 task definition（选项一）
- 通过 SDK 创建 task definition（选项二）
- 将上个环节中的镜像放到 ECS 中运行 grid search - 把左右均线组合都跑一遍
