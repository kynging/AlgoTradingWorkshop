## 快速创建金融数据湖

{{% notice note %}}
本实验建议在 us-east-1 区域进行。
{{% /notice  %}}

（此处应有架构图）

在开始之前，在 Notebook 中执行以下代码拷贝数据表：
```
my_name = 'xxx'
aws_region = 'us-east-1'
bucket = 'algo-trading-workshop-{}'.format(my_name)
table = 'stock_day'
database = 'stock-data'

!aws s3 cp s3://stock-public-data/{table}.csv s3://{bucket}/raw/{table}.csv --request-payer requester --region {aws_region}
```

**这个部分介绍如何使用 Glue 和 Athena 来快速进行数据 ELT**
- 通过 Glue 控制台创建 Glue 爬虫以及 ETL 任务（选项一）
- 通过 Athena 控制台直接建表并进行 ETL（选项二）
```
CREATE EXTERNAL TABLE IF NOT EXISTS stock_day_raw (
  ticker string,
  secID string,
  tradeDate string,
  openPrice double,
  highestPrice double,
  lowestPrice double,
  closePrice double,
  turnoverVol double,
  turnoverValue double,
  accumAdjFactor double,
  isOpen boolean
)
ROW FORMAT SERDE 'org.apache.hadoop.hive.serde2.OpenCSVSerde'
LOCATION 's3://algo-trading-workshop-xxx/raw'
TBLPROPERTIES ('skip.header.line.count'='1');
```
```
CREATE EXTERNAL TABLE IF NOT EXISTS stock_day (
  ticker string,
  secID string,
  tradedate string,
  openPrice double,
  highestPrice double,
  lowestPrice double,
  closePrice double,
  turnoverVol double,
  turnoverValue double,
  accumAdjFactor double,
  isOpen boolean
)
STORED AS parquet
LOCATION 's3://algo-trading-workshop-xxx/parquet'
```
```
INSERT INTO stock_day
SELECT *
FROM stock_day_raw;
```
- 使用 Glue DataBrew 进行操作（选项三，可选）
