## 按照最佳实践来部署一个云端VPC网络环境

{{% notice note %}}
本实验需要在us-east-1区域进行。
{{% /notice  %}}

CloudFormation 模板包含的内容：
- 创建一个包含 public、private、isolated 子网的 VPC
- 创建的 VPC 分别位于三个不同的可用区
- 公有子网：
    - 该子网内的资源会暴露在互联网上，可被用户或客户端直接访问。通常用于部署NAT Gateway, 堡垒机，ELB负载均衡器等；

实验步骤：

1. 打开CloudFormation的控制台，并创建新的堆栈：
https://console.aws.amazon.com/cloudformation/home?region=us-east-1#/stacks?filteringStatus=active&filteringText=&viewNested=true&hideStacks=false
![](/images/1.LandingZone/create_stack.png)
2. 在“创建堆栈”部分，填入为该实验准备的模版URL：[]()。点击【下一步】按钮。
输入以下的相关的参数，并点击【下一步】按钮。
* 堆栈名称：
* 任意选择AvailabilityZone三个可用区，如us-east-1a和us-east-1b
* 其他选项按照默认即可，如下图所示，点击【下一步】按钮。
![](/images/1.LandingZone/stack_detail.png)
在“配置堆栈选项”页面上，保留默认配置，并点击【下一步】按钮。
在“审核 SpapiWorkshopVPC”页面上，保留默认配置，点击【创建堆栈】按钮，并等待此模板的创建执行完毕，此过程大概约3分钟左右。
3. 查看资源
- 进入VPC控制台： https://console.aws.amazon.com/vpc/home?region=us-east-1#
- 查看创建好的VPC，子网，路由表，安全组，Internet Gateway，NAT Gateway等资源。
