## 通过 AWS 控制台创建 S3 存储桶和 ECS 集群

{{% notice note %}}
本实验建议在 us-east-1 区域进行。
{{% /notice  %}}

在这个环节中，我们将创建实验基础的 S3 存储桶和 ECS 集群。

### 创建 S3 存储桶

我们先创建一个 S3 存储桶用于存储实验数据，以及实验过程中产生的文件。

- 通过以下链接导航到 S3 控制台：[https://s3.console.aws.amazon.com/s3/home?region=us-east-1](https://s3.console.aws.amazon.com/s3/home?region=us-east-1)
- 点击右侧的 **Create Bucket**：
![](/images/0.2.aws_console/s3_console.png)

- 输入存储桶名称为 **algo-trading-workshop-您的名字简称**，并确保区域名为 **us-east-1**：
![](/images/0.2.aws_console/create_bucket.png)

- 创建成功后可以在控制台中看到新的存储桶：
![](/images/0.2.aws_console/s3_bucket.png)

### 创建 ECS 集群

接下来我们创建一个 ECS 集群。

- 通过以下链接导航到 ECS 控制台：[https://console.aws.amazon.com/ecs/home?region=us-east-1#/clusters](https://console.aws.amazon.com/ecs/home?region=us-east-1#/clusters)
- 点击 **Create Cluster**：
![](/images/0.2.aws_console/ecs_console.png)

- 在下一步中保持默认，点击 **Next step**：
![](/images/0.2.aws_console/ecs_template.png)

- 输入集群名称 **algo-trading-workshop**，点击 **Create**：
![](/images/0.2.aws_console/ecs_create_cluster.png)

- 创建成功后可以在控制台中看到新的 ECS 集群：
![](/images/0.2.aws_console/ecs_cluster.png)
