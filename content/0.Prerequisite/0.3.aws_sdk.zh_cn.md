## 使用 AWS SDK 创建 S3 存储桶和 ECS 集群

{{% notice note %}}
本实验建议在 us-east-1 区域进行。
{{% /notice  %}}

### 创建 Notebook 

在这一步中，我们将导航到 SageMaker 控制台在新创建的 Notebook 中运行 AWS SDK 的简单代码。

登录 AWS 控制台，并在 us-east-1 区域打开之前创建的 SageMaker Notebook：

- 跳转到 SageMaker 控制台：[https://us-east-1.console.aws.amazon.com/sagemaker/home?region=us-east-1#/](https://us-east-1.console.aws.amazon.com/sagemaker/home?region=us-east-1#/)
- 单击左侧的 **Notebook**，然后点击 **Notebook instances**
- 在右侧的 Notebook instances 界面，找到名为 **AlgoTradingWorkshop** 的 SageMaker Notebook 实例，并点击 **Open JupyterLab**：
![](/images/0.3.aws_sdk/open_jupyterlab.png)

控制台将会跳转到 JupyterLab 界面，在 JupyterLab 中创建一个新的 Notebook：

- 点击左上角的 **+** 按钮，这时会显示右侧的 **Launcher**
- 在 Launcher 中选择 **conda_python3** 内核
![](/images/0.3.aws_sdk/create_notebook.png)

- 点击**保存**按钮，并**重命名**这个 notebook 为 **aws_sdk.ipynb**
![](/images/0.3.aws_sdk/rename_notebook.png)

### 运行 AWS SDK 代码

在这一步中，我们将在刚刚创建的 Notebook 中运行 AWS SDK 的简单代码。

- 首先，我们定义一些环境变量。请将以下代码复制到 Notebook 的第一个 cell 运行。这里可以将 **my_name** 设置为自己姓名的简称：
```
my_name = ''
aws_region = 'us-east-1'
bucket = 'algo-trading-workshop-{}'.format(my_name)
```

![](/images/0.3.aws_sdk/notebook_1.png)

- 要使用 AWS SDK，接下来要用 pip 安装 boto3（AWS SDK for Python）。同样将以下代码复制到第二个 cell 运行：
```
!pip install botocore boto3
!pip show boto3
```

![](/images/0.3.aws_sdk/notebook_2.png)

- 接下来将以下代码复制到第二个 cell 运行，创建 S3 存储桶和 ECS 集群：
```
import boto3

s3 = boto3.client('s3', region_name=aws_region)
s3.create_bucket(Bucket=bucket)

ecs = boto3.client('ecs', region_name=aws_region)
ecs.create_cluster(clusterName='algo-trading-workshop')
```

![](/images/0.3.aws_sdk/notebook_3.png)

看到如上的结果就说明代码执行成功了。这些代码起到和 0.2 中控制台操作完全相同的作用。
