#### VPC 介绍
Amazon Virtual Private Cloud（VPC）允许您在 Amazon Web Services 云中预置一个逻辑隔离分区，并在虚拟网络中启动亚马逊云科技资源。您可以完全掌控您的虚拟联网环境，包括选择自己的 IP 地址范围、创建子网以及配置路由表和网络网关。VPC类似于传统网络，包括以下概念：

- 子网：VPC 中可用的一系列IP地址
- 路由表：一组称为路由的规则，用于确定将网络流量定向到何处。
- 网关：VPC 中资源和公网之间的网关。
- CIDR 段：用于 IP 地址分配和路由聚合
