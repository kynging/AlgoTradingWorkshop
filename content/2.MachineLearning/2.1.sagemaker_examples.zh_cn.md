## 使用 SageMaker 进行模型训练和部署

{{% notice note %}}
本实验建议在 us-east-1 区域进行。
{{% /notice  %}}

在这个部分，我们会介绍如何通过深度学习模型进行时间序列预测。时间序列分析和预测是一个在现代科学中非常具有挑战的领域。在使用历史数据进行预测的时候，如果我们能事先知道影响未来状态的所有因素，就能够通过回归算法快速找到未来与这些影响因素之间的关系。但现实情况中，我们往往无法事先知道股价的所有影响因素。因此在预测问题中，往往使用一些与市场行情相关的银子，比如指数的表现、同行业其他股票的表现、市场情绪等因子。深度学习算法可以寻找这些因子之间的关联性，并且具有 LSTM 的模型可以识别一些股价的历史规律和周期性变化，更好地对未来状态进行预测。

通常来讲，像 ARIMA (Autoregressive Integrated moving average) 之类的传统算法往往并不能在股价预测的场景取得很好的效果，而使用 RNN （循环神经网络）类深度学习算法会比传统的回归模型具有更好的效果。在这个环节中我们将专注于如何使用 SageMaker 进行模型的训练和部署。

接下来我们将提供训练一个时序预测模型的示例。通过这个示例，您可以看到如何通过 SageMaker 快速部署自定义模型，以及使用 AWS 托管的算法镜像。

![](/images/2.1.sagemaker_examples/)
（此处应有架构图）

### 使用自定义模型和容器镜像

我们在这里将展示使用自定义 TensorFlow 模型来运行时序预测的示例。

- 下载本实验使用的 Notebook 代码：[2.1.1.sagemaker_custom_rnn.ipynb](/files/2.1.1.sagemaker_custom_rnn.ipynb)
- 回到 SageMaker Notebook 界面，点击 **Upload Files** 按钮： 
![](/images/2.1.sagemaker_examples/custom_rnn_upload_files.png)

- 点击右上角的 **kernel** 选项：
![](/images/2.1.sagemaker_examples/custom_rnn_choose_kernel.png)
- 选择 **conda_python3**
![](/images/2.1.sagemaker_examples/custom_rnn_choose_kernel_2.png)

- 接下来，把第一个 cell 中的 **my_name** 变量修改为之前定义的值：
- 执行代码的第一个 cell，会创建一个名为 **sagemaker-custom-rnn** 的路径：
![](/images/2.1.sagemaker_examples/custom_rnn_create_directory.png)

- 下载这个压缩包：[2.1.1.sagemaker_custom_rnn.zip](/files/2.1.1.sagemaker_custom_rnn.zip)
- 将压缩包上传到 **sagemaker-custom-rnn** 路径下：
![](/images/2.1.sagemaker_examples/custom_rnn_upload_model.png)

- 在 **File** 标签下，选择打开一个新的 **Terminal**：
![](/images/2.1.sagemaker_examples/custom_rnn_open_terminal.png)

- 在 Terminal 中输入：
````
cd /home/ec2-user/SageMaker/sagemaker-custom-rnn
unzip 2.1.1.sagemaker_custom_rnn.zip
````

- 解压成功后，应该在 路径下生成了一个新的 **model** 路径：
![](/images/2.1.sagemaker_examples/custom_rnn_unzip_model.png)

这时可以继续执行 Notebook 代码了。

在这个示例中，我们构建了一个自定义算法的容器镜像，并且在 SageMaker 托管实例中完成了模型训练。您可能会注意到，我们已经在刚才解压缩的 **model** 路径中定义了算法的内容。

- 在这里我们通过 **COPY** 命令在构建 Docker 镜像的时候将其拷贝到了容器中。在 SageMaker 启动训练任务的时候，会自动执行 **/opt/ml/code** 路径下的 model 文件：
![](/images/2.1.sagemaker_examples/custom_rnn_dockerfile.png)

- 模型训练完成之后，我们可以查看一些训练数据的可视化，比如 loss 的梯度下降：
![](/images/2.1.sagemaker_examples/custom_rnn_loss_history.png)

在模型训练完成之后，我们将模型部署到了一个 SageMaker 终端节点。这个终端节点是完全由 SageMaker 托管的，部署完成之后可以导航到控制台中查看终端节点的信息：[https://us-east-1.console.aws.amazon.com/sagemaker/home?region=us-east-1#/endpoints](https://us-east-1.console.aws.amazon.com/sagemaker/home?region=us-east-1#/endpoints)

在最后我们创建了一个 predictor 类，通过这个类向终端节点发送推理请求，并生成预测结果：
![](/images/2.1.sagemaker_examples/custom_rnn_prediction_result.png)

虽然这个模型的预测效果有待提升，但您应该可以同这个过程了解了 SageMaker 的基础使用。接下来我们将再展示一个托管算法的示例。


### 使用 AWS 提供的 DeepAR 算法

我们在这里将展示使用 DeepAR 来运行时序预测的示例。与之前的自定义模型有所区别的是，DeepAR 能够提供基于概率的预测。这在蒙特卡洛模拟等场景中具有独特的用处。

- 下载本实验使用的 Notebook 代码：[2.1.2.sagemaker_deepar.ipynb](/files/2.1.2.sagemaker_deepar.ipynb)
- 回到 SageMaker Notebook 界面，点击 **Upload Files** 按钮： 
![](/images/2.1.sagemaker_examples/deepar_upload_files.png)

- 点击右上角的 **kernel** 选项：
![](/images/2.1.sagemaker_examples/deepar_choose_kernel.png)
- 选择 **conda_python3**
![](/images/2.1.sagemaker_examples/deepar_choose_kernel_2.png)

- 接下来，把第一个 cell 中的 **my_name** 变量修改为之前定义的值

这时可以继续执行 Notebook 代码了。

在这个示例中，我们使用 DeepAR 的托管容器镜像，在 SageMaker 托管实例中完成了模型训练。您可能会注意到，这个容器镜像是已经创建好并存放在 ECR 服务中的，不需要用户从头构建：
![](/images/2.1.sagemaker_examples/deepar_image_url.png)

与之前的示例相似，我们在训练模型之后，将模型部署到了一个终端节点。这个终端节点是完全由 SageMaker 托管的，部署完成之后可以导航到控制台中查看终端节点的信息：[https://us-east-1.console.aws.amazon.com/sagemaker/home?region=us-east-1#/endpoints](https://us-east-1.console.aws.amazon.com/sagemaker/home?region=us-east-1#/endpoints)

在最后我们创建了一个 predictor 类，通过这个类向终端节点发送推理请求，并生成预测结果：
![](/images/2.1.sagemaker_examples/deepar_prediction_result.png)

与传统时序预测不同的是，DeepAR 提供基于概率的预测。在上图的预测结果中，实线部分代表 50% quantile （即中位数）的预测值，而阴影部分则代表 10% quantile 至 90% quantile 的区间。

DeepAR 的优势在于可以轻易利用大量的并行时间序列。这对于大规模的预测模型（比如全市场的预测）非常有利。SageMaker 本身也提供了超参优化功能可以对模型进行调优。
> 关于如何使用超参优化对模型进行调优，可以参考：
> [https://docs.aws.amazon.com/zh_cn/sagemaker/latest/dg/automatic-model-tuning.html](https://docs.aws.amazon.com/zh_cn/sagemaker/latest/dg/automatic-model-tuning.html)
