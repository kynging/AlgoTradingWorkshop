如何使用hugo

这个页面不会提供给最终客户，只是向大家展示如何使用 hugo 搭建 workshop 网站。

  • 首先，这个网站的源代码储存在 https://github.com/kynging/algo-trading-workshop，请务必给个 star 然后 clone 到本地
  • 然后，去 hugo 的官方网站根据指示下载 hugo server：https://gohugo.io/getting-started/installing/
  • 下载成功后运行以下命令行启动 hugo server：
hugo server -D
  • 然后就可以去 localhost:1313 访问这个网站了
  • 如果需要修改绑定的 IP 和端口，运行：
hugo server -D --bind 0.0.0.0 --port xxx
